# Victor Atem Atem — Warrap State 2026

Multi-page website for Victor Atem Atem, SPLM candidate for Governor of Warrap State in South Sudan's 2026 general election.

## Pages

- Home
- Biography
- Manifesto
- News
- Gallery
- Campaign Schedule
- Contact
- Custom 404 page

## Deployment on Vercel

1. Import `SalvaAleu1/Victor-Atem` into Vercel.
2. Framework preset: **Other**.
3. Build command: leave empty.
4. Output directory: leave empty.
5. Deploy.

`vercel.json` enables clean URLs and basic security headers.
